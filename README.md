# Disaster Risk Management Research Portal · UNGRD

[![Quarto](https://img.shields.io/badge/Built%20with-Quarto-blue.svg)](https://quarto.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

This repository contains the source code for the **DRM Research Portal** (Investigaciones en Gestión del Riesgo de Desastres), an official platform by the **National Unit for Disaster Risk Management (UNGRD)** of Colombia.

The portal serves as a centralized hub for scientific and technical publications, books, and conference proceedings related to disaster risk knowledge, vulnerability analysis, and institutional capacity in Colombia.

## 🚀 Overview

The portal highlights several key research areas:
- **Hazard Analysis:** Technical studies on floods, earthquakes, landslides, and droughts.
- **Territorial Vulnerability:** Characterization of exposure and vulnerability conditions across the country.
- **Institutional Capacity:** Evaluation of the National System for Disaster Risk Management (SNGRD).
- **Risk Reduction:** Strategic interventions to mitigate existing risks and prevent new ones.

## 💻 Local Development

To run this project locally, you need to have [Quarto](https://quarto.org/docs/get-started/) installed.

1. Clone the repository:
   ```bash
   git clone https://github.com/scr-ungrd/investigaciones-grd-colombia.git
   cd investigaciones-grd-colombia
   ```

2. Preview the site:
   ```bash
   quarto preview
   ```

3. Render the site:
   ```bash
   quarto render
   ```
